# 布局手艺与修复 cookbook

目标：图面一眼能读懂。度量（交叉/共线重叠/穿块/斜线）是下限，可读性靠目视。
执行顺序与约束见 [SKILL.md](../SKILL.md)；本文只讲“怎么摆、怎么修”。

## 摆放原则

1. **分列**：按信号流拓扑 rank 从左到右分列；输入块在最左列，输出块在最右列。
2. **分行**：并行/互不依赖的块从上到下排；同列内按“邻居高度重心”排序，减少交叉。
3. **端口对齐**：Inport 移到消费者高度、Outport 移到生产者高度；多输入块的目的端口按源块高度排序分配。
4. **间距**：列间 ≥ horizontal（默认 60），行间 ≥ vertical（默认 40），给走廊和标签留空间；坐标 snap 到 grid。
5. **反馈走廊**：反馈线走图上方（或下方）专用水平走廊，每条反馈独占一条走廊 y；不得与前向线混走。
6. **分支树**：单输出供 >2 个消费者时，用共享干路 + 脊线 + 叶线的分支树（每个分支点 ≤2 支线），不要从端口放射多条长线。
7. **子系统边界 = 功能边界**：仅为省空间打包会破坏可读性；跨功能区域的长信号优先重新分区，而不是拉线。
8. **标签**：信号名靠近源端、放线下方；块名在块下方；密集区宁可加间距也不要叠标签。
9. **端口几何以实际为准**：Sum 用 `rectangular` 图标使输入端口排在左缘；但端口真实坐标由图标几何决定（Sum 矩形端口在奇数八分位、Inport/Gain 有外伸桩），不等于 p/(n+1) 近似。plan 的端点是近似值，落线时以 `PortHandles` 的 `Position` 吸附端点并保持相邻段正交，否则会出现斜线桩。

## 修复 cookbook（按度量热点顺序）

先修 `repair_order` 最靠前的 scope；scope 内先修参与交叉最多的线对组。每轮只改一组，改完重新导出 + 度量 + 渲染 + 看图。

| 症状 | 首选动作 | 次选动作 |
| --- | --- | --- |
| 两子系统间反复交叉 | 调整双方端口纵向顺序 / 同列块顺序 | 重新划分功能列 |
| 同源扇出交叉 | 消费者端口对齐；>2 消费者拆分支树 | 显式接口子系统 |
| 反馈线横穿前向区 | 反馈独占上/下走廊；Delay 放在环所属层级 | 调整环的分区 |
| 共线重叠 | 分开走廊 x / 走廊 y；不同信号不得共享线段 | 重排块 |
| 穿块 | 线绕块外走廊；块移出线路径 | 调整列宽/间距 |
| 斜线 | 改正交折线（水平+垂直） | 重排端口使直连成为可能 |
| 长绕行/多余折弯 | 缩短走廊、去掉重复转折 | 移动块使端口同高 |
| 标签遮挡 | 加间距 / 缩短信号名 / 移标签到源端下方 | 隐藏 From 冗余块名（tag 仍可见） |

比较一轮修改是否接受：先看 `crossing_events`，再 overlap、through、diagonal，再 Goto 对数，最后 bends/length。前一指标没改善时，不接受只让后一指标变差的修改。

**自动化建议（phase 1）**：`repair_suggest.py <geometry.json>` 在内存预演小改动（重排目的端口/反馈置顶、移动块对齐端口高度、同列行交换、走廊/feedback 槽位重分配），只输出带 `targets_crossings` 与预演收益的 ops JSON（`reorder_ports`/`move_block`/`swap_blocks`/`reassign_slot`），不碰模型。每轮经 SATK 应用一条、重导出+`layout_metrics` 裁判；预演用近似端口高度，最终以实测为准。**phase 2（结构级，仅建议、必须用户同意+SATK 执行）**：`restructure_branch_tree`（扇出改共享干路+脊线+叶线）与 `goto_from_conversion`（几何穷尽后受限 Goto/From 转换，`--include-goto` 显式请求或 phase-1 无改善时自动给出；遵守 scope 预算、禁 Inport→Goto）。两者带 `structural:true, requires_consent:true`，未经同意不得应用。功能分区/子系统边界调整仍完全人工。无改善候选时输出 `stopped_reason`，按停滞规则停止。

**几何手段穷尽后**才按预算裁决转换 Goto/From（先 1 条再复测）；仍残留 ≤2 交叉/≤2 线时按 SKILL.md 书面遗留 + PNG 复核处理。连续 3 轮无净改善：停止，报告受阻线对、受约束端口与建议的功能分区调整，不得无限重排。

## Goto/From 贴放

Goto 紧贴源块输出侧、From 紧贴消费者输入侧；桩线正交、不穿块、不新增交叉。窄缝贴靠可缩小 From 尺寸；From 块名与消费者块名重叠时可 `ShowName=off`（tag 必须可见且等于信号名）。

## Stateflow 图面

- 默认转移接 Chart/父状态顶部、目标放同层左上；OR 层级至少两个状态；AND 层级不接默认转移。
- 状态按行列网格摆；转移尽量正交，需要拐弯时用 connective junction 显式拐角（1 进 1 出的拐角 junction 是合法手艺，不是冗余）。
- 转移标签统一靠近起点或统一靠近中部；状态内文字不越界（API 读不到包围盒，只能目视）。
- `chart_metrics.py` 的计数基于 3 点采样，曲线会失真：**只作提示**。最终结论以 `render_check.m` 的 Chart PNG 逐张检查为准；MATLAB 渲染不可用时用 `render_chart.py` 重绘几何（含 junction）作替代证据，并注明不等同于编辑器渲染。

## 目视复核清单（每张 PNG）

块名/信号名/端口标签/参数是否遮挡或裁切；线是否交叉/重叠/穿块/多余折弯；块图标与端口是否可辨识；信号流左→右、并行上→下、反馈走廊是否清楚；Chart 状态框/转移/标签是否可读。密集区用更高 dpi（如 300）重渲染再看局部。任何图面修改后不得继续引用旧 PNG。
